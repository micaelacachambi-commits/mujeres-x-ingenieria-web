# Mujeres x Ingeniería - Sitio Web

Sitio web oficial de **Mujeres x Ingeniería**, organización de base de la Facultad de Ingeniería de la Universidad Nacional de Jujuy dedicada a reducir las brechas de género en STEM.

## 🚀 Tecnologías

- **React 18** - Framework de UI
- **TypeScript** - Tipado estático
- **Tailwind CSS v4** - Estilos y diseño responsivo
- **Vite** - Build tool y dev server
- **Lucide React** - Iconos modernos

## 🎨 Diseño

- **Colores de marca:**
  - Verde lima: #BECD0D
  - Violeta: #A700D1
  - Lila: #C577E8
  - Negro grafito: #262626
  - Blanco cálido: #E2E2E2

- **Tipografía:** Satoshi (alternativa a Degular)
- **Responsive:** Optimizado para móvil, tablet y desktop

## 📦 Instalación

```bash
# Instalar dependencias
pnpm install

# Ejecutar en desarrollo
pnpm dev

# Compilar para producción
pnpm build
```

## 🌐 Secciones

- **Hero** - Presentación principal
- **Quiénes somos** - Misión y pilares (Acceso, Permanencia, Desarrollo, Liderazgo)
- **Qué hacemos** - Acciones y programas
- **Comunidad** - Impacto y estadísticas
- **Observatorio** - Investigación y datos
- **Sumate** - Call to action y formulario
